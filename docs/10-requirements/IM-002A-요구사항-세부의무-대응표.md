# AX Link 요구사항 세부 의무 대응표 (IM-002A)

**2026년 AX 프로젝트 관리 운영 프레임워크 개발 용역**
발주 (재)전주정보문화산업진흥원 · 수행 유저인사이트(주)
**v0.1.10 초안** · 2026-11-25 · 검토용 · IM-002 유스케이스 명세서의 부록

> IM-001 요구사항 41건을 **독립적으로 검증할 수 있는 세부 의무** 147개로 나누고, 의무마다 어느 유스케이스·흐름·수용 기준(AC)·예제 시나리오·시험 자료·검증 방법으로 확인하는지와 **누락·미결**을 적는다.
> 「41건이 유스케이스에 연결됨」을 넘어, 요구사항의 본문·비고·조건·범위 경계가 빠짐없이 기준으로 이어졌는지를 보는 표다.
> 세부 의무 식별자(`SWFR.CON.007-o3` 꼴)는 **추적용 하위 식별자**이며 새 공식 요구사항 코드가 아니다. IM-001 의 코드 체계는 바뀌지 않는다.
