# 플랫폼 관리

플랫폼 관리자만 쓰는 화면을 적습니다. 발주기관과 계정 발급, AI 모델 설정, 서버 오류 기록, 인포 템플릿입니다.

| 항목 | 내용 |
|---|---|
| 화면 | 왼쪽 메뉴의 발주기관·계정, 서버 오류 기록, 인포 템플릿, 설정 창의 AI 모델 |
| 하는 사람 | 플랫폼 관리자 |
| 기준 | 2026-11-20 |

## 발주기관과 계정 {#accounts}

### 발주기관 만들기 {#create-org}

1. 발주기관·계정 화면의 새 발주기관 칸에 기관 이름을 넣습니다.
2. [만들기]를 누릅니다.

### 담당자 계정 발급 {#issue-account}

1. 왼쪽 목록에서 기관을 고릅니다.
2. 아이디와 이름을 넣고 [계정 발급]을 누릅니다.
3. 임시 비밀번호 창이 뜨면 [비밀번호 복사]로 복사해서 담당자에게 전합니다.

임시 비밀번호는 이 창에서 한 번만 보입니다. 닫으면 다시 볼 수 없습니다. 담당자에게는 처음 로그인한 뒤 비밀번호를 바꾸라고 안내합니다.

이 화면에서 만드는 계정은 발주기관 계정입니다. 용역사 계정은 발주기관이 보내는 사업 초대 링크로 가입합니다.

### 비밀번호 재발급과 중지 {#manage-account}

- 담당자가 비밀번호를 잊었으면 [비밀번호 재발급]을 누릅니다. 새 임시 비밀번호가 나오고 이전 비밀번호와 로그인 상태는 모두 풀립니다.
- 담당자가 그만두면 [중지]를 누릅니다. 다시 쓰게 하려면 [다시 사용]을 누릅니다.
- 계정은 지우지 않습니다. 그 계정이 남긴 기록을 보존하려는 것입니다.
- 자기 계정은 중지할 수 없습니다. 플랫폼 관리자 계정은 이 화면에서 비밀번호를 재설정하지 않습니다.

## AI 모델 설정 {#ai-model}

AI 질의가 쓰는 답변 모델을 정합니다. 플랫폼 전체에 하나만 있습니다.

1. 사용자 메뉴의 [설정]을 열고 AI 모델 탭을 고릅니다.
2. LLM 서버 주소를 넣고 [새로 고침]을 눌러 모델 목록을 받습니다.
3. 모델을 고르고 컨텍스트 길이와 한 번에 만들 최대 토큰을 정합니다.
4. [이 서버에서 재보기]로 답을 만드는 속도를 잽니다.
5. 저장합니다. "AI 모델 설정을 저장했습니다."가 나오면 된 것입니다.

모델을 바꾸면 그 뒤의 모든 질문에 바로 적용됩니다. 바꾼 뒤 AI 질의에서 몇 가지를 물어 답이 정상인지 봅니다.

## 서버 오류 기록 {#errors}

처리 중 오류로 끝난 요청의 목록입니다. 시각, 상태 코드, 요청 경로, 사용자, 메시지가 나옵니다.

- [스택 보기]로 자세한 내용을 엽니다.
- [새로 고침]으로 최근 기록을 다시 읽습니다.
- [모두 지우기]는 기록을 모두 지웁니다. 지운 기록은 되돌릴 수 없으니 필요하면 먼저 옮겨 둡니다.

사용자가 오류를 알려 오면 이 화면에서 그 시각의 기록을 찾아봅니다.

## 인포 템플릿 {#templates}

대시보드의 위젯과 AI 답변이 고르는 그림 23종의 목록입니다. 그림마다 언제 고르는지와 어떤 값을 받는지가 나옵니다. 보기만 하는 화면입니다. 위젯이나 답의 그림이 이상할 때 어떤 템플릿이 골라졌는지 맞춰 보는 데 씁니다.

## 다른 역할의 화면 {#other-roles}

플랫폼 관리자는 모든 사업을 볼 수 있습니다. 사용자 매뉴얼도 모든 문서와 단락이 보이고, 역할별 단락 위에는 누구에게 보이는지가 적혀 있습니다.

플랫폼 관리자는 발주기관·용역사의 업무 판단을 하지 않습니다. 요구사항 명세서 등록·제출, 요구사항 목록 확정·돌려보내기, 요구사항 상태 지정, 산출물 승인·반려, 확인 요청 등록·확인완료·다시 요청, 작업 완료 확인이 여기에 듭니다. 관리자 화면에는 이 단추가 없고, 서버도 거절합니다.

참여 업체·사용자 할당, 수집 주기, 스냅샷 수동 기록, 대시보드 구성 같은 사업 관리는 운영 지원을 위해 관리자도 할 수 있습니다. 평소에는 그 사업의 발주기관이 합니다.

예전에 관리자가 처리한 기록(요구사항 목록 확정, 요구사항 상태 지정)은 지우지 않고 그대로 둡니다. 화면에는 처리한 사람 이름 뒤에 「(관리자)」가 붙습니다.
