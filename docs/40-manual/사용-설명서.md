# 사용 설명서

AX Link 의 기능별 설명서다. 기능마다 화면과 하는 사람, 흐름, 규칙, 읽는 형식, 오류와 해결, 제한, 관련 문서 순서로 적는다.
앱의 사용 설명서 화면은 이 파일을 그대로 보여 준다.

## 처음 쓰는 순서 {#getting-started}

1. **도구를 붙인다.** 용역사의 GitHub·Redmine 을 사업에 연결하고 첫 수집을 돌린다. → [도구 연동](도구-연동-가이드.md)
2. **요구사항을 등록한다.** 요구사항 명세서를 올려 목록을 만들고 발주기관이 확정한다. → [요구사항 등록](요구사항-등록.md)
3. **커밋·이슈에 요구사항 ID 를 적는다.** 적힌 ID 로 요구사항과 이어진다. → [도구 연동 › 저장소 규약](도구-연동-가이드.md#conventions)

## 기능 {#features}

| 기능 | 무엇을 하나 | 하는 사람 |
|---|---|---|
| [도구 연동](도구-연동-가이드.md) | GitHub·Redmine 연결, 수집, 권한, 수집한 것이 어디로 가는지 | 용역사 · 발주기관 |
| [요구사항 등록](요구사항-등록.md) | 용역사가 명세서를 등록하고 발주기관이 요구사항 목록으로 확정 | 용역사(등록) · 발주기관(확정) |

다른 기능(진행 상황, 일정, 산출물, 확인 요청, 질의)의 설명서는 이어서 쓴다.

설명서 화면 위의 **이 문서 PDF**·**전체 PDF** 단추로 PDF 를 만들 수 있다. 인쇄 화면이 열리면 그림이 다 불러와진 뒤 **PDF로 저장**을 누르고, 인쇄 창의 대상을 "PDF로 저장"으로 고른다. 전체 PDF 는 표지 뒤에 목차 순서대로 문서마다 새 쪽에서 시작한다.

## 공통 원칙 {#principles}

- **도구는 읽기만 한다.** AX Link 는 GitHub·Redmine 에 아무것도 쓰지 않는다.
- **숫자는 집계에서만 나온다.** 화면과 AI 답변의 숫자는 수집한 데이터를 센 값이다. AI 가 숫자를 만들지 않는다.
- **적힌 ID 로만 잇는다.** 요구사항과 커밋·이슈는 요구사항 ID 가 적혀 있을 때만 이어진다.
- **ID 는 적을 때 같이 적는다.** 커밋·이슈에 ID 를 빠뜨리면 나중에 이을 방법이 없다.
