# AI 질의

사업 현황을 말로 묻고 답을 받는 화면이다. 답에는 근거가 된 문서나 이슈가 함께 나온다.

| 항목 | 내용 |
|---|---|
| 화면 | 왼쪽 메뉴의 [새 질문]과 질문 목록 |
| 하는 사람 | 발주기관 |
| 기준 | 2026-11-09 |

## 답이 만들어지는 방식 {#how}

AI 가 마음대로 답을 지어내지 않도록 정해 둔 규칙이 있다.

- 숫자는 집계 값을 그대로 쓴다. "이슈가 몇 건이야" 같은 질문의 숫자는 현황 화면과 같은 집계에서 나온다. AI 는 그 숫자로 문장만 만든다.
- 근거가 없으면 답하지 않는다. 올린 문서에서 질문과 맞는 내용을 찾지 못하면 근거가 부족하다고 말한다.
- 출처를 붙인다. 문서에서 찾은 내용에는 각주 번호가 붙고, 누르면 원문 위치가 열린다.
- 근거에 없는 숫자가 든 문장은 화면에 나가기 전에 숨긴다.

## 묻기 {#ask}

1. 사업을 연 상태에서 왼쪽 메뉴의 [새 질문]을 누른다. 사업 밖에서 물으면 입력칸에 @ 를 쳐서 사업을 고를 수 있다.
2. 질문을 적고 [질문 보내기]를 누른다.
3. 답이 나오는 중에 그만두려면 [답변 중지]를 누른다.

이렇게 물으면 잘 답한다.

- 이번 주 일정이 늦어진 작업은 무엇이야
- 미제출 산출물 목록 보여 줘
- 열린 리스크 가운데 심각한 것은
- 납품 산출물은 몇 종이야 (올린 과업지시서에서 찾는다)

## 근거 보기 {#sources}

답 안의 [1] 같은 각주나 아래의 근거 산출물을 누르면 오른쪽에 원문이 열린다. 문서 안에서 다른 말을 찾으려면 [이 문서에서 찾기]를 쓴다.

답 아래에 답의 종류가 작게 붙을 때가 있다.

| 표시 | 뜻 |
|---|---|
| 일부만 답함 | 질문의 일부만 답했다. 못 한 부분은 답 끝에 적혀 있다 |
| 근거 없는 수치 문장 숨김 | 근거에 없는 숫자가 든 문장을 뺐다 |
| 되묻기 | 질문을 어느 쪽으로 볼지 골라 달라는 것이다 |
| 값 없음 | 아직 수집된 값이 없다 |
| 문서 없음, 맞는 근거 없음 | 올린 문서가 없거나 질문에 맞는 내용이 없다 |
| 지원하지 않는 질문 | 답할 조회 항목이 아직 없다 |
| 조회 오류 | 조회 중 오류가 났다. 값이 없다는 뜻은 아니다 |
| 문서 검색 멈춤 | 검색 모델 설정 문제로 문서 검색이 멈췄다. 관리자에게 알린다 |
| 사업 밖 질문 | 사업과 관계없는 질문이다 |
| 모델 장애, 집계 값만 | AI 모델 서버를 쓸 수 없어 집계 값만 보여 준다 |

답 아래의 [도움이 됨], [도움이 안 됨]으로 의견을 남길 수 있다. 이어서 물어볼 만한 질문이 단추로 나오면 눌러서 바로 물을 수 있다.

## 질문 목록 {#history}

물은 질문은 왼쪽 메뉴에 남는다. 사업 안에서는 그 사업의 질문만, 사업 밖에서는 최근 질문이 보인다. 질문 옆의 메뉴에서 고정, 이름 변경, 삭제를 할 수 있다. 고정한 질문은 목록 위에 있다.
