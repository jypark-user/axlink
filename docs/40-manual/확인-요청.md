# 확인 요청

발주기관이 용역사에게 무언가를 확인해 달라고 요청하고, 용역사가 조치한 뒤 보고하고, 발주기관이 확인해 닫는 화면이다. 작업이 끝났는지 발주기관이 확인하는 작업 완료 확인도 여기서 한다.

| 항목 | 내용 |
|---|---|
| 화면 | 사업을 고른 뒤 현황, 확인 요청 |
| 하는 사람 | 요청과 확인은 발주기관, 조치 보고는 용역사 |
| 기준 | 2026-11-16 |

## 흐름 {#flow}

| 단계 | 누가 | 하는 일 | 상태 |
|---|---|---|---|
| 1 | 발주기관 | 대상을 골라 요청을 등록한다 | 요청 |
| 2 | 용역사 | 조치하고 결과를 보고한다 | 조치보고 |
| 3 | 발주기관 | 보고를 보고 확인완료하거나 다시 요청한다 | 확인완료 또는 요청 |

다시 요청하면 요청 상태로 돌아가고 "재요청 N"이 붙는다.

요청을 등록하면 그때 대상의 상태(진척, 우선순위 같은 값)가 같이 저장된다. 보고를 확인할 때 "요청 시점과 지금"을 나란히 볼 수 있다.

요청할 수 있는 대상은 WBS 항목, 산출물, 이슈, 리스크, 지표다.

<!-- 대상: 발주기관 -->
## 요청 등록 {#create}

1. [요청 등록]을 누른다.
2. 대상 종류를 고르고 대상을 고른다. 대상이 많으면 검색 칸에 번호나 이름 일부를 적는다. 띄어쓰기는 상관없고, 여러 낱말을 적으면 모두 들어간 것만 남는다. 하나만 남으면 Enter 로 고를 수 있다. 등록 시점의 상태(실적률·파일 대조·정식 제출·승인·이슈 상태·지표값)가 요청과 함께 저장된다.
3. 요청 제목과 요청 내용을 적는다. 무엇을 확인하고 싶은지 구체적으로 적는다.
4. [등록]을 누른다.

## 보고 확인 {#confirm}

1. 목록에서 상태가 조치보고인 요청을 연다.
2. 용역사의 조치 결과와 요청 시점과 지금의 비교를 본다.
3. 충분하면 [확인완료]를 누른다.
4. 부족하면 다시 요청할 내용을 적고 [다시 요청]을 누른다.

확인완료는 발주기관만 할 수 있다. 플랫폼 관리자가 대신 닫지 않는다.

## 작업 완료 확인 {#completion}

WBS 작업이 실제로 끝났는지 확인하는 요청이다. 확인한 작업은 일정 화면의 완료 확인율에 들어간다.

1. [요청 등록]에서 대상 종류를 WBS 항목으로 고른다.
2. 요청 목적에서 작업 완료 확인 요청을 고른다.
3. 용역사가 완료 근거를 하나 이상 붙여 보고한다.
4. 근거를 확인했으면 확인란에 표시하고 [작업 완료 확인]을 누른다.

확인을 거두려면 완료 확인 철회 사유를 적고 [완료 확인 철회]를 누른다.

한 작업에 진행 중인 완료 확인 요청은 하나만 둘 수 있다. 요청한 뒤 WBS 의 작업명이나 산출물 열이 바뀌면 확인할 수 없다. 바뀐 내용으로 다시 요청한다. 이미 확인한 작업의 범위가 바뀌면 일정 화면에 재확인 필요로 나온다.
<!-- /대상 -->

<!-- 대상: 관리자 -->
플랫폼 관리자는 확인 요청과 조치 기록을 보기만 한다. 요청 등록, 조치 보고, 확인완료, 다시 요청, 작업 완료 확인과 철회는 하지 않는다. 화면에 해당 단추가 없고, API 로 시도해도 「플랫폼 관리자는 발주기관·용역사의 업무 판단을 대신하지 않습니다」로 거절된다. 2026-11-16 전에는 관리자도 일반 요청을 등록할 수 있었다.
<!-- /대상 -->

<!-- 대상: 용역사 -->
## 조치 보고 {#report}

발주기관이 요청을 등록하면 알림이 오고 목록에 요청 상태로 보인다.

1. 요청을 연다.
2. 요청 내용대로 조치한다. 조치는 원래 도구(저장소, Redmine)나 산출물 화면에서 한다.
3. 조치 결과를 적는다. 무엇을 어디서 고쳤는지 적는다.
4. [조치 보고]를 누른다.

작업 완료 확인 요청이면 완료 근거를 하나 이상 붙여야 보고할 수 있다. [근거 추가]로 산출물이나 링크를 더한다.

발주기관이 다시 요청하면 요청 상태로 돌아온다. 다시 요청한 내용을 보고 조치해서 다시 보고한다.
<!-- /대상 -->

## 화면에 나오는 문구 {#errors}

| 문구 | 뜻과 할 일 |
|---|---|
| 이 작업에는 진행 중인 완료 확인 요청이 이미 있습니다. | 그 요청을 끝내고 새로 요청한다 |
| 이미 완료 확인된 작업입니다. 다시 확인하려면 먼저 철회하세요. | 완료 확인을 철회한 뒤 요청한다 |
| 요청 뒤 작업명이나 산출물 열이 바뀌었습니다. 바뀐 내용으로 다시 요청하세요. | WBS 가 바뀌었다. 새로 요청한다 |
| 보고된 요청만 확인완료할 수 있습니다. | 용역사의 조치 보고를 기다린다 |
| 조치 보고는 용역사가 합니다. | 용역사 계정으로 보고한다 |
