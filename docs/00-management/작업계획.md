## 전제 변경 — 파일럿 기반

수행기관 파일럿 `ax-link-ui-base`를 구현 기반으로 삼는다.
요구사항 41건 대비 **구현 25 · 부분 5 · 없음 7 · 충돌 1 · 확인 3** (`docs/20-design/파일럿-대조표.md`).

작업 성격이 **"만들기"에서 "차이 메우기 + 통합"** 으로 바뀐다.

### W2 · 08.31~09.04 — 조사 + 커넥터 보완

- D1 읽기 전용 검증 · D2 청크 원문 위치 · D3 근거 게이트 (조사 → 결론을 설계서에 반영)

- 자기참조 프로젝트 **WBS 작성** (PM-002 양식) — 진척 기준선

### W3 · 09.07~09.11 — 수집 재현 → **M2**

- GitHub · Redmine 커넥터 실환경 연결 · 대상 선택 · 연결 진단
- E 파일럿 수직 슬라이스 → 전체 경로 확장
- **M2 완료조건: 대표 도구 2종 반복 수집 3회 재현 시연**

### W4~W5 · 09.14~09.25 — **A1 WBS 진척 산정** (핵심 구간)

- WBS 파서 제품화 — 가변 헤더 대응, 항목·가중치·계획기간·연결 산출물 인식

- 산출물 파일 인식 · WBS 항목–산출물 매칭
- 수준별 저하 로직 (L1~L4) · 추정 표기
- **A1이 이 사업의 차별점이다. 파일럿에 없는 유일한 대형 기능이므로 여유를 여기에 쓴다.**

### W6 · 09.28~09.30 — A2 + A3 → **M3**

- A3 일별 스냅샷 · 추이 (상시 가동 시작은 09월 중순 NAS 이전 시점)
- A2 확인 요청 · 조치 보고 — 요청 시점 관측 스냅샷 · 상태 관리 · 미처리 건수 표시
- **M3: 중간보고 — 표준 모델 · 진척률 · 스냅샷 · 워크스페이스 시연**

### W7~W8 · 10.01~10.16 — 문서 처리 마감 + 폐쇄망

- HWP·HWPX 추출 실측 검증 (개체 구조 보존 수준 확인)
- 청킹 원문 위치 · 한국어 임베딩 색인 정합성 (D2 결과 반영)
- **B3 폐쇄망 구동 검증** — AX Link를 GPU 서버로 이전, 외부 차단
- 근거 게이트 임계값 조정 (D3 결과 반영)

### W9 · 10.19~10.23 — LLM 전환 + 통합 → **M4**

- **C1 LLM `:cloud` → 로컬 모델 전환** (설정 변경 · `LlmPort` 구조상 코드 수정 없음)
- 대표 질의세트 전 항목 응답 검증
- B4 E2E 관리순환 시연 구성 — 확인 → 조치 → 재수집 → 갱신
- **M4: End-to-End 관리순환 시연**

### W10~W12 · 10.26~11.13 — 시험·문서 → **M5**

- 시험 케이스 작성 및 수행 (IM-005) · 결함 조치 (IM-006)
- 설계서(IM-003, `ARC-###`) · 사용자매뉴얼(IM-007) 정리
- **사례 조사** — 최종보고서 필수 항목
- 최종 결과보고서 초안
- **M5: 최종보고 발표**

### W13~W14 · 11.16~11.30 — 인도 → **M6**

> ⚠️ **2026-08-27 ARC-001(파이썬 전면 전환)로 아래 판단이 무효화되었다.**
> 이 절의 일정은 **전면 재수립 대기 중**이다. 재수립 전까지 아래를 근거로 삼지 않는다.

~~**버퍼가 없던 W7~W9 구간이 해소되었다.** RAG 파이프라인이 파일럿에서 이미 동작하므로
남은 일은 모델 전환과 폐쇄망 검증이고, 신규 개발이 아니다.~~

**무효 사유** — 파일럿 백엔드를 실행하지 않으므로 "RAG 파이프라인이 이미 동작한다"는
전제가 사라졌다. W7~W9 는 다시 **신규 개발 구간**이며 버퍼가 없다.
상세는 [`docs/20-design/ARC-001-백엔드-언어-파이썬-전환.md`](../20-design/ARC-001-백엔드-언어-파이썬-전환.md) §5.

**W4~W5(A1)가 최대 위험 구간이라는 판단도 재검토 대상이다.** 전환 후에는 커넥터·표준화·
시맨틱 레이어가 전부 신규 개발이라 위험이 특정 구간에 몰리지 않고 전 구간에 퍼진다.
