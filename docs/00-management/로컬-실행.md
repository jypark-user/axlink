# 로컬 실행 절차

파이썬 백엔드(FastAPI) + React 프런트 + PostgreSQL(docker) 3개를 띄운다.
근거는 [ARC-001](../20-design/ARC-001-백엔드-언어-파이썬-전환.md).

## 1. 인프라 (PostgreSQL + pgvector + Flyway)

```bash
docker compose -f infra/docker-compose.yml up -d postgres
docker compose -f infra/docker-compose.yml run --rm flyway   # V1~V19 적용
```

- 호스트에 로컬 PostgreSQL 이 있어 컨테이너는 **15432** 로 노출한다.
- pgvector·pg_trgm·pgcrypto 확장은 V1 이 설치한다.

## 2. 백엔드 (FastAPI, 8080)

```bash
py -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m uvicorn app.main:app --port 8080 --reload
```

DB 접속은 환경변수로 바꾼다. 기본값은 `.venv` 없이도 붙게 맞춰 뒀다.

```
AXLINK_DATABASE_URL=postgresql://axlink:axlink@localhost:15432/axlink
AXLINK_JWT_SECRET=...   # 운영에서는 반드시 주입한다
```

## 3. 프런트 (Vite, 5173)

```bash
cd frontend && npm ci && npm run dev
```

`/api` 는 vite 가 8080 으로 프록시한다(`frontend/vite.config.ts`).
브라우저에서 <http://localhost:5173> 을 연다.

## Redmine (샘플 원천, 3000)

작업 이슈·리스크·결함의 원천 도구다. 구조(트래커·버전 M1~M6·커스텀 필드 REQ ID·REST 활성화)는
스크립트가 만들고, **이슈 내용은 사람이 넣는다** — 생성기로 심은 이슈는 샘플 대표성이 없다.

```bash
docker compose -f infra/docker-compose.yml up -d redmine-db redmine   # 첫 부팅 1~2분
docker cp infra/redmine/axlink_init.rake axlink-redmine:/usr/src/redmine/lib/tasks/
docker exec -e SECRET_KEY_BASE=change-me-in-local-env axlink-redmine bin/rake axlink:init
```

- 관리자: `admin` / `axlink-admin` (로컬 전용). API 키는 rake 출력 또는 「내 계정」에서
- 커넥터 연결값: base URL `http://localhost:3000` · 대상 `axlink` · 인증은 API 키

## 개발용 계정 (시드 V4 · V20)

| 아이디 | 비밀번호 | 역할 | 보이는 사업 |
|---|---|---|---|
| `r1` | `admin` | SUPER_ADMIN | 전체 |
| `r2` | `admin` | CLIENT (한국디지털공사) | 자기 조직 사업 |
| `r3` | `admin` | CONTRACTOR (넥스트소프트) | 배정된 사업 |

로그인 식별자는 이메일이 아니라 아이디다(V20). 형식 제약이 없어 이메일 주소를
아이디로 써도 된다.

## 테스트

**시험용 DB 를 따로 쓴다.** 스위트가 시드 사업의 연결과 그 연결이 수집한 데이터를
지우기 때문이다. 개발 DB 에 그냥 돌리면 수집분이 날아간다.

```bash
# 처음 한 번만
docker exec axlink-postgres psql -U axlink -d postgres -c "create database axlink_test owner axlink"
docker compose -f infra/docker-compose.yml run --rm flyway   -url=jdbc:postgresql://postgres:5432/axlink_test -user=axlink -password=axlink   -locations=filesystem:/flyway/sql -connectRetries=10 migrate

AXLINK_DATABASE_URL=postgresql://axlink:axlink@localhost:15432/axlink_test   .venv/Scripts/python -m pytest      # DB 없으면 skip
.venv/Scripts/python -m ruff check app tests
```

Ollama 가 떠 있으면 실모델 검증(`tests/test_embedding_live.py`)까지 돌고, 없으면 skip 된다.
나머지 테스트는 Fake 임베딩으로 돈다.

```bash
cd frontend && npx tsc --noEmit && npx vitest run
```
