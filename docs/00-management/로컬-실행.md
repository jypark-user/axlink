# 로컬 실행 절차

파이썬 백엔드(FastAPI) + React 프런트 + PostgreSQL(docker) 3개를 띄운다.
근거는 [ARC-001](../20-design/ARC-001-백엔드-언어-파이썬-전환.md).

## 1. 인프라 (PostgreSQL + pgvector + Flyway)

```bash
docker compose -f infra/docker-compose.yml up -d postgres
docker compose -f infra/docker-compose.yml run --rm flyway   # V1~V19 적용
```

- 호스트에 로컬 PostgreSQL 이 있어 컨테이너는 **15432** 로 노출한다.
- pgvector·pg_trgm·pgcrypto 확장은 V1 이 설치한다.

## 2. 백엔드 (FastAPI, 8080)

```bash
py -m venv .venv
.venv/Scripts/python -m pip install -e ".[dev]"
.venv/Scripts/python -m uvicorn app.main:app --port 8080 --reload
```

DB 접속은 환경변수로 바꾼다. 기본값은 `.venv` 없이도 붙게 맞춰 뒀다.

```
AXLINK_DATABASE_URL=postgresql://axlink:axlink@localhost:15432/axlink
AXLINK_JWT_SECRET=...   # 운영에서는 반드시 주입한다
```

## 3. 프런트 (Vite, 5173)

```bash
cd frontend && npm ci && npm run dev
```

`/api` 는 vite 가 8080 으로 프록시한다(`frontend/vite.config.ts`).
브라우저에서 <http://localhost:5173> 을 연다.

## 개발용 계정 (시드 V4/V5)

| 이메일 | 비밀번호 | 역할 | 보이는 사업 |
|---|---|---|---|
| `r1@admin.com` | `admin` | SUPER_ADMIN | 전체 |
| `r2@admin.com` | `admin` | CLIENT (한국디지털공사) | 자기 조직 사업 |
| `r3@admin.com` | `admin` | CONTRACTOR (넥스트소프트) | 배정된 사업 |
