## 알려진 실패 표시 (2026-11-06, 사용자 결정 2안)

명세와 제품이 다른 것으로 확인된 시나리오 41건을 `tests/scenarios/conftest.py` 의 `KNOWN_FAILURES` 에 결함·결정 ID 와 함께 `xfail(strict=True)` 로 표시했다. PR CI 는 이 표시로 초록이 되고, 결함이 고쳐져 통과하면 XPASS 로 실패해 표를 갱신하라고 알린다. 기록 도구는 xfail 을 「실패(알려진 결함)」, XPASS 를 「통과」로 읽는다.
