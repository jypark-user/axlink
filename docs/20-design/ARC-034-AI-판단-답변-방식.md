## 1. 문제

지표 기반은 모델이 질문을 지표·문서·목록·일정 중 하나로 판정하고, 서버가 그 하나만 집계해 넘긴다. 수치는 안전하지만 두 가지가 약했다.

- 판단이 좁다. 모델은 고르고 옮겨 쓸 뿐이라 "지금 가장 급한 게 뭐야" 처럼 여러 자원을 엮어 우선순위를 정하는 질문에 약하다. 11-24 폐쇄망 시험에서 결함·리스크 요약을 묻자 결함 수치를 모른다고 답하고 리스크를 일반 이슈와 섞었다.
- 느리다. 판정과 문장 생성으로 모델을 두 번 부른다. 같은 시험에서 응답 중앙값이 92초였다.

## 2. 결정

답변 방식을 둘로 두고 플랫폼 관리자가 설정에서 고른다(`answer_setting`, V75). 행이 없으면 지표 기반이다.

| | 지표 기반 (STRUCTURED, 기본) | AI 판단 (AI_JUDGE) |
|---|---|---|
| 판정 | 모델이 질문을 한 갈래로 분류 | 없음 |
| 넘기는 재료 | 고른 지표 하나 또는 문서·목록 하나 | 사업 자원 전체 + 질문에 닿는 문서 조각 |
| 모델 호출 | 2회(판정, 생성) | 1회 |
| 모델이 하는 일 | 문장 구성 | 자원 선택, 해석, 원인 연결, 우선순위, 조치 제안 |
| 그림(인포 템플릿) | 고른 템플릿으로 그림 | 그리지 않는다. 글로 답한다 |
| 수치 검문 | 적용 | 적용(같은 검문) |

권장 질문을 눌러 들어온 질문은 키가 이미 정해져 있어 방식과 상관없이 지표 기반으로 답한다.

## 3. 사업 자원

`app/rag/judge.py` 가 질문 범위의 사업(최대 3개)에 대해 서버에서 모은다. 값은 전부 메뉴 화면과 같은 시맨틱 레이어·표준 모델에서 온다.

| 절 | 내용 | 출처 |
|---|---|---|
| 핵심 지표 | 진척률·계획 진척률·편차·지연 작업, 일정 준수율, 요구사항 이행률, 일반 이슈·결함·리스크 건수와 처리율, 산출물 승인률·미제출, 코드 활동량 | `semantic.run` |
| 나눠 센 값 | 열린 일반 이슈(심각도별), 열린 리스크(심각도별), 일반 이슈(상태별) | `semantic.run` |
| WBS 작업 | 말단 작업별 기간·가중치·실적·기준일 계획선·산출물·종료일 경과 여부 | `current_wbs_rows` |
| 스냅샷 추이 | 최근 14일의 진척률·계획선·지연 작업 수 | `progress_snapshot` |
| 목록 | 요구사항, 처리 중 일반 이슈, 결함, 리스크, 산출물(종류별 앞 30건과 전체 건수) | `entity_table` |
| 근거 문서 | 질문으로 검색해 근거 게이트를 넘은 조각 | `search_with_vector` |

나눠 센 값은 11-25 실모델 확인에서 넣었다. 모델이 리스크 목록 행을 세어 "심각도 높음 N건" 을 만들자 수치 검문이 막았다. 건수는 서버가 세어 주고, 모델에게는 행을 세지 말라고 지시한다.

## 4. 절대 규칙과의 관계

- 규칙 1(수치): 모델은 자원에 적힌 값만 옮긴다. 내보내는 문장은 지표 기반과 같은 수치 검문을 지나며, 검문의 근거는 사업 자원 줄과 문서 조각이다.
- 규칙 2(화면): AI 판단은 그림을 만들지 않는다. 화면 구성은 지표 기반과 메뉴 화면의 몫이다.
- 규칙 3(근거): 자원과 문서 밖의 사실은 말하지 않는다. 답에 문서 각주 [n] 와 자원 표시 [자원: 절 이름] 를 붙인다. 문서 조각은 근거 게이트를 넘은 것만 넣는다. 자원이 늘 있으므로 "근거 부족" 으로 모델 호출을 막는 일은 없고, 자원으로 답할 수 없으면 모델이 그렇다고 말한다.

## 5. 확인

- 시험: `tests/test_ask_ai_judge.py`. 설정 기본값과 권한, 판정 생략과 1회 호출, 자원이 프롬프트에 들어가는지, 자원에 없는 숫자 차단, 지표 기반 유지.
- 11-25 실모델(qwen3.5:122b, 시험 DB 시드 사업) 세 질문 비교: AI 판단 40~45초, 지표 기반 42~197초. AI 판단은 세 질문 모두 막힘 없이 답했고 우선순위와 조치를 제안했다.

## 6. 남은 것

- 자원이 커지면 프롬프트가 길어진다. 사업이 많거나 목록이 길면 절을 줄이는 기준이 필요하다.
- 답이 자원을 가리키는 표시([자원: …])는 아직 화면에서 눌러 열리지 않는다.
- 대표 질의세트로 두 방식의 정답률을 나란히 재는 시험은 하지 않았다.
