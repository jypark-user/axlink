# AX Link 인프라 배치 방안

v0.1 · 2026-08-21 기록 · **결정 시점: 09월 (GPU 확보 시)**

## 1. 왜 물리적으로 분리해야 하는가

개발 PC 한 대에 전부 올려도 기능은 돌아간다. 그러나 아래 네 가지가 걸린다.

### ① 폐쇄망 검증이 성립하지 않는다 — 가장 중요

`QUR.RAG.001`(외부 클라우드 LLM 비의존) · `QUR.SEC.001`(외부 인터넷 없이 설치·구동)의
검증 방법이 `T`(테스트)다. **개발 PC는 인터넷이 열려 있어 격리 검증이 불가능하다.**

*"인터넷 끊고 테스트했습니다"* 는 최종보고서 근거로 약하다.
**AX Link만 외부 접속이 차단된 환경에 두어야** 실증이 된다.
이 사업의 핵심 명분이 폐쇄망 온프레미스이므로, 검증 환경 자체가 산출물의 일부다.

### ② 일별 스냅샷은 상시 가동이 전제

`SWFR.PIP.005` 일별 스냅샷은 매일 돌아야 추이가 그려진다.
**PC를 끄면 그날의 데이터가 비고, 진척 추이 차트에 구멍이 생긴다.**
시연 시점(10월)에 8~10월 추이를 보여주려면 그 사이 계속 켜져 있어야 한다.

### ③ 역할 구분이 흐려진다

```
Redmine   = 용역업체의 관리 도구       ← 남의 시스템
AX Link   = 발주기관의 프레임워크      ← 우리 시스템
```

같은 머신의 `localhost`로 붙으면 **커넥터가 실제 네트워크를 타는지 검증되지 않는다.**
인증·타임아웃·rate limit·연결 실패 진단이 모두 실제 조건에서 확인되어야 한다.

### ④ 시연 신뢰성

발주기관 앞에서 개발자 노트북을 열어 보여주는 것과
서버 주소로 접속해 보여주는 것은 설득력이 다르다.

## 2. 구성안

### 최소 (1대 + NAS)

| 위치 | 구성 | 역할 |
|---|---|---|
| **GPU 서버** | AX Link 앱 · PostgreSQL+pgvector · Ollama | 발주기관 시스템 |
| **Synology NAS** | Redmine + PostgreSQL (Container Manager) | 용역업체 도구 |

NAS는 상시 가동이고 Docker를 지원한다. 추가 비용 없이 ②③을 만족한다.
GPU 서버의 외부 인터넷을 차단하면 ①도 성립한다 (Redmine·GitHub 접근은 사내망/허용 목록으로).

### 권장 (2대)

| 위치 | 구성 |
|---|---|
| **서버 A — GPU** | AX Link 앱 · PostgreSQL+pgvector · Ollama · **외부 인터넷 차단** |
| **서버 B — 소형/NAS** | Redmine · (선택) 데모 사이트 리버스 프록시 |

### 이상 (3대 — PoC 범위 초과)

운영·검증·개발 환경 분리. 본 과업 예산으로는 불필요.

## 3. 전환 계획

| 시점 | 위치 | 비고 |
|---|---|---|
| **W1~W3 (8월~9월 초)** | 이사님 PC Docker Desktop | 개발 편의 우선. 스냅샷 데이터는 이 구간에 없어도 무방 |
| **W4~W5 (9월 중순)** | Redmine을 **NAS로 이전** | 상시 가동 시작 → 스냅샷 추이 누적 시작 |
| **W7 (10월 초)** | AX Link를 **GPU 서버로 이전** · 외부 차단 | 폐쇄망 검증 착수 |
| **W9 (10월 하순)** | 데모 사이트 공개 · M4 시연 | 발주기관 접속 확인 |

> **9월 중순이 실질적인 전환 시점이다.** 스냅샷 추이를 10월 시연에서 보여주려면
> 최소 한 달치 데이터가 필요하고, 그러려면 9월 중순부터는 상시 가동되어야 한다.

## 4. 지금 결정하지 않아도 되는 이유

`infra/docker-compose.yml` 하나로 전체 스택이 정의되어 있다.
위치를 옮기는 작업은 **compose 파일 복사 + `.env` 값 변경**이 전부다.

```
이전 시 바꾸는 것
  REDMINE_URL        localhost:3000  →  http://nas.local:3000
  POSTGRES_DSN       localhost:5432  →  서버 내부 주소
  LLM_BASE_URL       localhost:11434 →  GPU 서버 주소
```

**커넥터가 `base_url`을 설정으로 받는 구조**(`SWFR.CON.002`)라 코드 수정이 없다.
이 요구사항이 인프라 이동성까지 커버한다.
