## 1. 보호 대상

| 대상 | 왜 지키나 |
|---|---|
| 도구 인증정보(GitHub 토큰, Redmine API 키) | 새면 용역사 저장소·이슈 도구에 접근할 수 있다 |
| 수집 데이터(이슈·커밋·요구사항·산출물 문서) | 사업 내부 자료다. 다른 사업·다른 업체에 보이면 안 된다 |
| 계정과 세션 | 발주기관의 판단(확정·승인·확인완료)이 계정에 묶인다 |
| 원천 도구 | AX Link 는 원천에 아무것도 쓰지 않아야 한다 |
| 답변의 신뢰성 | 화면·답변의 수치가 틀리면 관리 판단이 틀린다 |

## 2. 원칙

1. **원천은 읽기만 한다.** 수집은 GET 만 쓴다.
2. **사업 범위를 넘지 않는다.** 모든 사업 API 는 호출자가 볼 수 있는 사업과 교차한 뒤 실행한다.
3. **비밀은 저장소·화면·로그에 두지 않는다.** 환경변수로 받고, 저장할 때는 암호화한다.
4. **질의·응답은 외부 클라우드에 기대지 않는다.** 답변 모델과 임베딩은 온프레미스 모델 서버(Ollama)로 돌린다.
   폐쇄망 조건(`QUR.RAG.001`)은 이 질의·응답 경로에 걸린다. 용역사 도구(GitHub·Redmine)에서 자료를 가져오는 수집은
   그 도구에 닿아야 하므로, 도구가 인터넷에 있으면 수집 서버에서 등록한 도구 주소로 가는 읽기 연결만 연다(운영 수칙 7).
5. **LLM 에는 권한을 주지 않는다.** 모델은 문장만 쓴다. 도구 호출·쓰기·수치 생성이 없다.

## 4. 운영 수칙

공개 데모 환경(5173)과 납품 설치에 똑같이 적용한다.

1. 설치 직후 마이그레이션이 만든 기본 계정(`admin@axlink.co.kr`, 개발 계정 r1~r3)의 비밀번호를 바꾸거나 계정을 정지한다. 외부에 여는 것은 그 뒤에 한다.
2. `AXLINK_JWT_SECRET`(32자 이상)·`AXLINK_SECRET_KEY` 를 새로 만들어 넣는다. 암호화 키는 바꾸지 않는다. 바꾸면 저장한 토큰을 풀 수 없다. `.env` 사본을 안전한 곳에 따로 둔다.
3. `AXLINK_SERVER_NAMES` 에 받을 호스트를 적는다. 비우면 모든 호스트를 받는다.
4. 도구 토큰은 읽기 권한만 준 것을 쓴다(GitHub fine-grained 읽기 전용, Redmine 조회 권한 계정).
5. 폐쇄망에서는 모델 서버에 클라우드 모델(`*-cloud`)을 두지 않고, 모델 서버의 외부망을 막는다. 모델 파일은 반입 목록(`docs/40-manual/폐쇄망-반입-목록.md`)대로 들인다.
6. DB(5432)·모델 서버(11434) 포트는 밖에 열지 않는다.
7. 바깥으로 나가는 연결은 수집 서버(API)에서 등록한 도구 주소로 가는 HTTPS 읽기 연결만 허용한다. 모델 서버·DB 는 바깥과 닿지 않는다. 도구를 기관 내부망에 두면 바깥 연결은 필요 없다.

## 5. 남은 위험과 처리

PoC 범위(과업지시서 Ⅱ.1 나항·Ⅱ.5 나항)에서 받아들이는 것과 인도 전에 고치는 것을 가른다.

| # | 위험 | 지금 | 처리 |
|---|---|---|---|
| R1 | 로그인 실패 횟수 제한이 없었다. 비밀번호 대입에 막힘이 없었다 | **11-23 보완.** 같은 아이디로 10분 안에 10번 틀리면 10분 동안 로그인을 받지 않는다(`app/auth/throttle.py`). 관리자가 비밀번호를 재설정하면 바로 풀린다 | 기록이 API 프로세스 메모리에 있어 재시작하면 지워진다. PoC 수용 |
| R2 | 기본 계정이 마이그레이션으로 생기고 운영 기동 검사가 이를 보지 않는다 | 운영 수칙 1로 관리 | 수칙 유지. 후속: 운영 모드에서 기본 비밀번호 계정이 남아 있으면 경고 |
| R3 | 클라우드 모델을 고르지 못하게 막는 설정이 없다 | 모델 서버에 클라우드 모델이 없으면 고를 수 없다 | 운영 수칙 5. 개발 PC(5173)는 클라우드 모델을 쓴다(사용자 결정, 내부망 모델로 바꾸면 온프레미스) |
| R4 | 콘텐츠 보안 정책(CSP)이 없다 | 그 밖의 보안 헤더는 11-23 적용 | 화면 전체를 확인한 뒤 적용(인라인 스타일 영향 확인 필요) |
| R5 | 첫 로그인 때 비밀번호 변경을 강제하지 않는다. 비밀번호 규칙은 8자 이상뿐이다 | 관리자 발급 임시 비밀번호는 무작위 16자 | PoC 수용. 운영 확산 때 정책 강화 |
| R6 | 초대 링크 토큰이 주소 경로에 있어 접속 기록에 남을 수 있다 | 초대 토큰은 한 번 쓰면 끝나고 기한이 있다 | PoC 수용 |
| R7 | API 가 앞단 프록시 헤더를 모든 주소에서 믿는다(`--forwarded-allow-ips "*"`) | API 포트는 웹 컨테이너에만 열린다 | 운영 구성에서 API 포트를 밖에 열지 않는 것으로 관리 |
| R8 | 연결 주소의 사설 IP 를 막지 않는다 | 연결 등록은 사업 담당자·용역사만. 폐쇄망에서는 내부 도구를 부르는 것이 목적이다 | PoC 수용 |
| R9 | 파이썬 의존성 잠금 파일·자동 취약점 알림이 없다 | 이미지는 Trivy 로 검사 | 후속 |
| R10 | 5173 은 API 를 root 로 돌리고(GH-124), DB·모델 서버 포트가 모든 인터페이스에 열려 있다 | 이미지 기본은 uid 10001. 포트 제한은 `docker-compose.ext.yml` 에 준비됨 | 5173 다음 반영 때 적용 |
| R11 | 마이그레이션 이미지의 Jackson 2.15.2 HIGH 7건(GH-157) | 반영 때 한 번 돌고 끝나는 컨테이너다 | 10-23 사용자 수용. Flyway 판 올림 때 해소 |
