# ARC-022 답변 모델과 검색 모델 분리

| | |
|---|---|
| 상태 | **확정** |
| 일자 | 2026-10-07 |
| 결정 | 유저인사이트(주) 수행 책임자 |
| 관련 | `SWFR.RAG.002` `SWFR.RAG.007` `ARC-011` `ARC-014` |

---

## 1. 결정

AI 모델 설정을 **답변 모델**과 **검색 모델** 두 영역으로 나눈다.

| | 답변 모델 (LLM) | 검색 모델 (임베딩) |
|---|---|---|
| 하는 일 | 질문 분류, 답변 생성, 문서 초안 | 문서 색인, 질문과 비슷한 문서 찾기 |
| 정하는 곳 | 설정 화면(DB `llm_setting`). 없으면 환경변수 | 환경변수 `AXLINK_EMBEDDING_MODEL` 만 |
| 화면에서 바꾸기 | 된다. 저장 전에 짧은 생성을 해 본다 | 안 된다. 현황만 보인다 |

질문 분류와 답변 생성은 같은 모델을 쓴다. 화면에 그렇게 적는다.

## 2. 왜

- 답변 모델 목록에 임베딩 전용 모델(bge-m3)이 함께 떠서 고를 수 있었다. 고르면 질의가 전부 실패한다.
- 검색 모델은 색인과 묶여 있다. 차원이 같아도 다른 모델이 만든 벡터를 섞으면 검색이 조용히 틀린다.
  기존 색인을 안전하게 다시 만드는 기능은 아직 없다.

## 3. 용도 판단

Ollama `/api/tags` 가 주는 `capabilities` 만 본다. 이름으로 짐작하지 않는다(V50 에 그대로 저장).

| capabilities | 판단 | 답변 모델로 |
|---|---|---|
| `completion` 포함 | ANSWER | 고를 수 있다 |
| `embedding` 만 | EMBEDDING | 화면에서 못 고르고 API 도 400 `MODEL_ROLE_MISMATCH` |
| 없음 · 그 밖 | UNKNOWN (확인 필요) | 고를 수 있으나 저장 전 확인을 넘어야 한다 |

저장할 때는 용도와 상관없이 그 모델로 짧은 생성을 실제로 해 본다. 안 되면 400
`MODEL_CHECK_FAILED` 로 저장하지 않는다. 성공 시각은 `llm_model_cache.verified_at` 에 남는다.

## 4. 검색 모델과 색인이 다를 때

`doc_chunk.embedding_model` 에 지금 검색 모델과 다른 이름이 하나라도 있으면 **문서 검색과 색인만
멈춘다**(503 `AI_EMBEDDING_MISMATCH`). 질의는 `SEARCH_DISABLED`(문서 검색 멈춤)로 끝나고 모델을
부르지 않는다. 집계·목록 같은 문서 밖 답은 그대로 된다.

API 기동 자체를 막는 안과 견줬다.

| | 기동을 막는다 | 검색·색인만 멈춘다 (채택) |
|---|---|---|
| 섞임 방지 | 된다 | 된다 |
| 영향 범위 | 로그인·진척·이슈까지 전부 멈춤 | 문서 검색과 색인만 |
| 원인 확인 | 로그를 봐야 한다 | 관리자 설정 화면 검색 모델 영역 |
| 복구 | 환경변수 되돌리고 재기동 | 같다. 화면에서 바로 확인된다 |

차원이 `doc_chunk.embedding` 컬럼과 다르면 저장 자체가 안 되므로 그때는 지금처럼 기동을 막는다
(`indexing.verify_dimension`).

같은 소스를 다시 색인하면서 그 소스의 낡은 벡터를 갈아 끼우는 것은 막지 않는다. 지워질 벡터라
섞임이 아니다. 다른 소스에 다른 모델 벡터가 남아 있으면 막는다.

복구는 환경변수를 색인 모델에 맞추고 API 를 다시 띄우는 것이다. 자동 재색인이나 색인 삭제는 하지
않는다.

## 5. 라우팅 캐시

판정 캐시 키(ARC-014)에 답변 모델의 **서버 주소·모델·`num_ctx`·`num_predict`** 를 넣는다. 모델
이름만 넣으면 같은 이름의 다른 서버나 문맥 길이를 바꾼 뒤에도 앞 판정을 다시 쓴다. 시간 제한은
판정에 영향이 없어 넣지 않는다. 키가 바뀌면 옛 판정은 쓰이지 않고 남아 있다가 자연히 밀려난다.

## 6. API

| | |
|---|---|
| `GET /api/ai/settings` | 답변 모델. `source`(DB·ENV), `usedFor`, 모델별 `purpose`·`capabilities`·`verifiedAt` |
| `PUT /api/ai/settings` | 임베딩 전용 거절, 짧은 생성 확인 뒤 저장 |
| `GET /api/ai/embedding` | 검색 모델, 서버, 차원, 색인 모델별 조각 수, 맞는지와 이유 |
| `PUT /api/ai/embedding` | 늘 409 `EMBEDDING_CHANGE_BLOCKED` |

모두 플랫폼 관리자만.
